# Прогнозирование и обнаружение аномалий во временных рядах

Учебный проект по анализу временных рядов.  
Выполнен в рамках учебной практики.

## Описание проекта

В данном проекте реализован прототип системы, выполняющей две функции:
- **Прогнозирование** будущих значений временного ряда (на основе исторических данных).
- **Обнаружение аномалий** – выявление резких выбросов, отклоняющихся от обычного поведения.

## Данные

Использован искусственный временной ряд `art_daily_jumpsup.csv` из бенчмарка **Numenta Anomaly Benchmark (NAB)**.

- **Источник:** [Kaggle NAB](https://www.kaggle.com/datasets/boltzmannbrain/nab)  
- **Структура:** столбцы `timestamp` (время с шагом 5 минут) и `value` (числовой показатель).  
- **Особенность:** данные содержат суточную сезонность и резкие пиковые выбросы (аномалии).
